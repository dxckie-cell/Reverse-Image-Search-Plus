# Reverse Image Search Plus

A [Revenge](https://github.com/revenge-mod/revenge-bundle) plugin: long-press a message with an image and tap **Reverse Image Search** (right below "Save Image") to open it in Google Lens.

Based on [Reverse Image Search](https://github.com/everestmcarthur/revenge-plugins/tree/main/plugins/reverse-image-search) by Rosie.

Install in Revenge (Settings → Plugins → `+`):

```
https://dxckie-cell.github.io/Reverse-Image-Search-Plus/
```

Built and published to GitHub Pages by `.github/workflows/deploy.yml` on every push to `main`.
